# Проверка и границы этой базы

## Что входит в текущую редакцию

- Основы Java, ООП, коллекции, generics, exceptions, streams, equals/hashCode и immutability.
- JVM, память, GC, class loading, диагностика и многопоточность.
- Git, terminal, алгоритмы, SQL, PostgreSQL, JDBC, JPA и Hibernate.
- Spring Core, Spring Boot, аннотации, MVC, validation, Data JPA, Security и тестирование.
- HTTP/REST, архитектура, SOLID, Maven, Docker, CI/CD, Redis, Kafka.
- Production: observability, надёжность, безопасность и диагностика.
- Личные шпаргалки, учебный маршрут, трекер и шаблоны.

## Как использовать

Это личная учебная база и справочник, а не подтверждение, что все темы уже освоены. Я отмечаю тему изученной после самостоятельного объяснения и практики. Примеры компактные и не всегда являются готовым production-кодом.

## Версии и точность

- Примеры Spring ориентированы преимущественно на Spring Boot 3+/Spring Framework 6+ и `jakarta.*`, если не указано иное.
- Поведение зависит от версии Java, Spring, Hibernate, PostgreSQL и конфигурации.
- Для API, security, транзакций и production-настроек сверяюсь с документацией конкретной версии.
- Автоматическая проверка ссылок и структуры Markdown не заменяет экспертную проверку каждого возможного окружения.

## Автоматические проверки

При сборке проверяю ZIP, внутренние Markdown-ссылки, парность fenced code blocks и наличие ключевых разделов.
