# Java Core: основы языка

## Что такое Java
Java — статически типизированный объектно-ориентированный язык. Код компилируется в байткод, который исполняет JVM. Поэтому один и тот же байткод можно запускать на разных платформах с подходящей JVM.

## Типы
Примитивы: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`.
Ссылочные типы: классы, интерфейсы, массивы, перечисления и другие объекты.

```java
int age = 24;
long id = 100L;
double price = 19.99;
boolean active = true;
String name = "Nikita";
```
Примитивная переменная хранит значение. Ссылочная переменная хранит ссылку на объект или `null`.

## Условия, циклы и методы
```java
if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}

for (int i = 0; i < 3; i++) {
    System.out.println(i);
}

public int sum(int a, int b) {
    return a + b;
}
```
Метод — именованный блок кода. Параметры передают данные внутрь, `return` возвращает результат.

## Классы и объекты
Класс описывает состояние и поведение. Объект — экземпляр класса.

```java
public class User {
    private final long id;
    private String name;

    public User(long id, String name) {
        this.id = id;
        this.name = name;
    }
    public long getId() { return id; }
    public String getName() { return name; }
}
```
`private` запрещает прямой доступ к полю снаружи. `final` запрещает переназначить поле после инициализации.

## ООП
- Инкапсуляция — объект контролирует доступ к своему состоянию.
- Наследование — класс расширяет другой класс; я использую, если отношение «является» действительно корректно.
- Полиморфизм — разные реализации можно использовать через общий интерфейс.
- Абстракция — выделение важного контракта и сокрытие деталей.

Интерфейс описывает контракт. Абстрактный класс может содержать общее состояние и реализацию.

## equals и hashCode
Если `a.equals(b)` возвращает `true`, их `hashCode()` обязан совпадать. Обратное неверно. Это важно для HashMap и HashSet.

## String
`String` неизменяем. Для многократной сборки строки в цикле я использую `StringBuilder`.

## Практика
Я создаю `Task` с id, title и status. Сделай поля приватными, я проверяю входные данные, я добавляю изменение статуса и тесты.

## Передача аргументов и ссылки

Java всегда передаёт аргументы **по значению**. Для объекта копируется значение ссылки, поэтому метод может я изменяють состояние того же объекта, но переназначение локального параметра не я изменяют переменную вызывающего кода.

```java
void rename(User user) {
    user.setName("Alex"); // меняет тот же объект
    user = new User(2, "Sam"); // меняет только локальную копию ссылки
}
```

## == и equals

- Для примитивов `==` сравнивает значения.
- Для ссылок `==` проверяет, указывают ли переменные на один объект.
- `equals()` сравнивает логическое равенство по реализации класса.
- Если переопределяешь `equals`, обычно нужно согласованно переопределить `hashCode`.

## static, final и конструктор

- `static` относится к классу, а не к конкретному объекту.
- `final` у переменной запрещает повторное присваивание; для ссылки это не делает сам объект неизменяемым.
- Конструктор инициализирует новый объект и не имеет типа возвращаемого значения.
- Перегрузка (overload) — методы с одинаковым именем, но разными параметрами.
- Переопределение (override) — реализация метода родителя/интерфейса в подклассе.

## String и сравнение строк

`String` immutable: операции вроде `replace` возвращают новую строку, исходную не меняют.
```java
String name = "Ann";
name.toUpperCase();       // результат проигнорирован, name прежний
name = name.toUpperCase();
```
Для сравнения содержимого я использую `equals`, а не `==`.

## null и примитивные обёртки

`Integer`, `Long`, `Boolean` — ссылочные обёртки примитивов; они могут быть `null`. Автораспаковка `Integer` в `int` при `null` вызовет `NullPointerException`. Для API, где отсутствие значения допустимо, продумай явное представление отсутствия.

## Область видимости и модификаторы доступа

- `private` — только внутри класса.
- package-private (без модификатора) — внутри пакета.
- `protected` — пакет и наследники с правилами доступа Java.
- `public` — отовсюду, где тип доступен.

Я не делаю всё `public`: открывай только необходимый контракт.


## enum, record и массивы

`enum` задаёт ограниченный набор констант:
```java
enum Status { NEW, IN_PROGRESS, DONE }
```
Я использую enum, когда значение выбирается из известного набора. Я не храню статус как произвольную строку, если набор фиксирован.

`record` — компактный способ объявить класс-носитель данных:
```java
public record UserDto(long id, String name) {}
```
Компилятор создаёт constructor, accessors, `equals`, `hashCode` и `toString`. Компоненты record final, но если внутри лежит изменяемый объект, это не делает его глубоко неизменяемым.

Массив имеет фиксированную длину:
```java
int[] numbers = {1, 2, 3};
System.out.println(numbers.length);
```
Для коллекции с изменяемым размером чаще я использую `ArrayList`.

## Интерфейс и абстрактный класс

Интерфейс задаёт контракт, который могут реализовать разные классы. Абстрактный класс может хранит общее состояние и частичную реализацию. Класс может реализовать несколько интерфейсов, но наследоваться только от одного класса.

## Перегрузка и переопределение

Перегрузка определяется набором параметров и выбирается компилятором. Переопределение заменяет унаследованную реализацию и участвует в динамическом полиморфизме. Аннотация `@Override` помогает компилятору проверить, что метод действительно переопределяет метод родителя/интерфейса.
